# FireLamp Neo — Android UI prototype

Тёмный интерфейс с фиолетовыми акцентами: экраны «Главная», «Эффекты» и «Настройки».

## Что заложено
- Адрес контроллера по умолчанию: `192.168.1.40`, порт `8888`.
- Элементы интерфейса: питание, яркость, скорость, выбор оттенка, список демонстрационных эффектов и сетевые настройки.

## Важно
Это пока **прототип интерфейса**, а не готовая замена FireLamp. Список эффектов демонстрационный: соответствие эффектам оригинального приложения и контроллера ещё не подтверждено. Кнопки и переключатели меняют только состояние экрана — команды лампе не отправляются.

В APK FireLamp 3.1.7 обнаружены признаки использования UDP и HTTP, но точный формат пакетов, команды и ответы контроллера пока не восстановлены. Поэтому отображение IP или статуса в интерфейсе не означает, что лампа действительно подключена.

## Как получить APK без компьютера

1. На телефоне откройте GitHub и войдите в аккаунт или создайте его.
2. Создайте новый **публичный** репозиторий, например `FireLampNeo`.
3. Загрузите в репозиторий всё содержимое этой папки, сохраняя структуру каталогов. Важно загрузить и скрытую папку `.github` с файлом workflow.
4. Откройте вкладку **Actions** репозитория.
5. Выберите **Build FireLamp Neo APK** и нажмите **Run workflow** (если сборка не запустилась автоматически после загрузки файлов).
6. Дождитесь зелёной отметки успешной сборки, откройте завершённый запуск и скачайте артефакт `FireLamp-Neo-debug-apk`.
7. Распакуйте ZIP-архив артефакта — внутри будет `app-debug.apk`. Android может попросить разрешить установку приложения из используемого браузера или файлового менеджера.

GitHub Actions собирает **отладочный APK**. Он подходит для установки и проверки интерфейса, но пока не управляет лампой. Для настоящего управления следующим этапом нужно восстановить протокол оригинального APK и проверить его с Wemos D1 mini.

## Сборка в Android Studio

Нужны Android SDK 35, JDK 17 и Gradle 8.9. Выполните `gradle assembleDebug` из корня проекта.
